# Estudar fora sendo brasileiro / Studying Abroad as a Brazilian

A free, bilingual (PT/EN) roadmap for Brazilian high schoolers applying to US undergrad — no paid consulting needed.

> Test policies, fees and deadlines change every year. Always verify on each university's official site.

## 1. Linha do tempo / Timeline

1. **1º ano:** grades count from day one. Pick 2–3 activities and go deep.
2. **2º ano:** first SAT/ACT + English test (TOEFL, IELTS or Duolingo). Start a project with real impact.
3. **July before 3º ano:** build a 10–15 school list and draft the Common App essay.
4. **Aug–Oct of 3º ano:** ask for recommendations, translate transcripts, decide on ED/EA (common deadline: Nov 1).
5. **Nov–Jan:** Regular Decision + financial aid forms (CSS Profile / ISFAA).
6. **Mar–Apr:** results; compare aid offers and decide by May 1.

## 2. Montando a aplicação / Building the application

| Peça / Piece | O que importa / What matters | Dica / Tip for Brazilians |
| --- | --- | --- |
| Transcript | Grades across 3 years + course rigor | Official translation; explain the 0–10 scale |
| SAT/ACT | Check if required or test-optional | Send only if at/above the school's mid-range |
| English | TOEFL, IELTS or Duolingo | Check each school's minimum |
| Essays | Your voice, one specific story | Show Brazilian context without over-explaining |
| Activities | Depth, leadership, impact | Olympiads (OBMEP, OBF), social projects and jobs count |
| Recommendations | 2 teachers + counselor | Brief them with a summary and a sample letter |

## 3. Dinheiro / Money

- **Need-blind for internationals:** few schools — check each one's current list.
- **Need-aware:** need may weigh in; still worth applying.
- **Merit scholarships:** common at state and smaller private schools.
- **Brazilian support:** Fundação Estudar, Instituto Ponte, Fundación Lemann.
- **Fee waivers:** ask your counselor or the university directly.

## 4. Erros comuns / Common mistakes

1. Applying only to Ivies — balance reach, target, safety.
2. Leaving the essay for November.
3. 15 shallow activities instead of 3 deep ones.
4. Ignoring financial aid until admission.
5. Translating the essay from Portuguese — write in English.
6. Not asking for help — Brazilian alumni in the US often reply on LinkedIn.

## 5. Recursos gratuitos / Free resources

- [Common App](https://www.commonapp.org)
- [Khan Academy — official SAT prep](https://www.khanacademy.org/digital-sat)
- [EducationUSA](https://educationusa.state.gov)
- [Schoolhouse.world — free SAT tutoring](https://schoolhouse.world)
- ViaMundi Education — international admissions mentorship
